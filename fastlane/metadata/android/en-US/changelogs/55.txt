New:
* Adjusting the edge swipe width now paints the zone down the edges it would occupy, so you can see what the number means.
* The settings preview shows two rows, so the spacing between favorites is something you can see while you set it.

Fixed:
* The A-Z strip no longer appears over edit layout, whatever the always-show setting says.
* The A-Z strip range editor always shows the strip now, even with always-show off, and hides the rest of the home screen so the range is set against the wallpaper.
* Edit layout's text uses the text color you chose, at full strength, and dims the wallpaper behind it. It was faint grey on whatever happened to be there, and invisible for anyone using dark text.
* The A-Z strip range button is easier to see as a button.
* Both dim sliders move one percent at a time, like everything else.
* Reduced the delay when pressing the very edge of the screen to open the app list, on the parts of the strip where Android was still claiming the touch for its back gesture.
* "Show letters in the app list" is now "Show A-Z in app list".
